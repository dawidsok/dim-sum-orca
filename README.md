# Dim Sum for Orca

Dim Sum themes for [Orca](https://github.com/stablyai/orca): UI themes with matching terminal colors.

Variants: Dim Sum, Darker, Mono, Mono Light, Paper, Sunset, Wave.

## Install

```sh
orca plugin install dawidsok/dim-sum-orca
```

Then choose a variant under **Settings → Appearance**.
